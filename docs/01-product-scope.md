# 01 - MVP Scope and Release Boundaries

## Product Goal
Help students convert raw study material into active learning workflows through AI.

## Target Users
- High school and university students
- Exam-focused learners
- Online course learners with heavy reading loads

## Release Boundaries

## Release 1 (Portfolio MVP)
Must include:
- Email/password and Google authentication
- User profile and onboarding
- Note/PDF upload
- AI-generated summary
- AI-generated quiz
- Flashcard generation
- Basic progress dashboard

## Release 2 (Enhanced Learning)
- AI tutor chat assistant
- OCR from scanned notes/images
- Smart reminders
- Stronger analytics

## Release 3 (Scale + Retention)
- Group study collaboration
- Full offline sync
- Adaptive quiz difficulty personalization

## MVP Success Criteria
- User can sign in and upload study material in < 2 minutes
- AI summary generated in < 10 seconds for standard notes
- Quiz + flashcards can be generated and attempted without errors
- User sees measurable progress metrics after at least one session
